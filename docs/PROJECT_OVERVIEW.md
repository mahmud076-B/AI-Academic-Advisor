# Project Overview

## Project Name

AI Academic Advisor - An Intelligent Campus Memory

## Product Description

AI Academic Advisor is an AI-powered academic assistant for university students.

The system understands a student's academic context and combines it with relevant campus experiences and memories to provide personalized academic assistance.

## Problem

University students often need academic guidance that depends on their personal academic context and campus-specific knowledge.

Known context may include:

- Name
- Student ID
- Department
- Batch
- Section
- Semester
- Courses
- Class routine

## Solution

The product will provide a modern AI assistant experience that can use student academic context and relevant Campus Memory entries to answer questions in a personalized and campus-specific way.

## Core Concept

Campus Memory is a stored collection of useful campus experiences, problems, solutions, recommendations, and academic experiences shared by students.

Campus Memory does not mean retraining the LLM.

The intended concept is to retrieve relevant stored information and provide it as context to the AI.

## Target Users

Primary users:

- University students

Other user types: Not decided yet.

## Product Vision

Create a modern, premium, clean AI assistant for academic life that feels like a SaaS/chat application rather than a traditional university management system.

## Current Scope

Initial MVP concepts include:

- Department
