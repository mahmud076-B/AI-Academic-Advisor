# Development Roadmap

## Development Approach

The project will be built incrementally in very small steps using AI-assisted development.

The user is a beginner developer with limited experience in:

- GitHub
- Databases
- Backend development
- APIs
- System architecture
- Deployment

Development should therefore be beginner-friendly, carefully explained, and verifiable at each step.
