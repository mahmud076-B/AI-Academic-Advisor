# UI/UX Specification

## Product Feel

The main interface should feel like a modern, premium, clean AI assistant similar to a modern SaaS/chat application.

It should not feel like a traditional university management system.

## Screens

Known MVP screen concepts may include:

- Student authentication
- Student onboarding
- Academic profile
- Courses
- Class routine
- AI chat
- Chat history
- Campus Memory
- Experience sharing
